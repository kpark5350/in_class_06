# Midnight Route 13

Halloween Coding Challenge for Web Programming.

## Team Information
- Group: UG-S03
- Category: Undergraduate Solo
- Developer: Ki Hyun Park

## Project Description
Midnight Route 13 is a three-scene Halloween website created using only HTML5 and CSS3.

The project follows a short Halloween story through a haunted house, a candy trail, and a final witch flight before midnight.

## Technologies
- HTML5
- CSS3
- CSS Grid
- Flexbox
- CSS Animations
- CSS Variables
- Media Queries

## Features
- Three CSS-only interactive scenes
- Halloween-themed animations
- Responsive design
- Keyboard accessible navigation
- Reduced-motion support
- No JavaScript used

## Images
The project includes Halloween images for:
- Haunted House
- Black Cat
- Ghost
- Jack-o'-lantern
- Trick-or-Treater
- Witch on Broomstick

## Accessibility
The site includes visible keyboard focus states, semantic HTML5 elements, responsive layouts, and reduced-motion support.

## JavaScript
No JavaScript was used in this project.
